## Phase C verdicts (v4.4 roadmap, re-judged post-hygiene)

- **C1 source-file basename boost — KEEP (neutral-but-principled).** Already
  shipped in 746e84d. Ablation changes nothing on all 12 tasks: the ranker's
  `_tokenize` splits CamelCase ("OAuth2" → "auth2"), so the exact-stem match
  rarely fires; the orchestrator-level `query_match` widening (v4.4 Phase 3,
  CamelCase-aware) is what actually rescues basename matches now. Kept as a
  tie-breaker for literal lowercase module-name queries; the roadmap's missing
  outcome tests added in `packages/ranking/tests/test_source_file_boost.py`.
  (The roadmap spec's own test values were unsatisfiable — 0.55 × 1.3 = 0.715
  < 0.72 — and were adjusted.)
- **C2 semantic re-rank default-on — REVERT the default; feature stays
  opt-in.** With a working sentence-transformers env, default-on scores F1
  0.537 vs 0.613 lexical-only (−0.076): the additive boost lifts low-relevance
  tail items past the adaptive top-k cut (avg pack 3.2 → 3.5 items, precision
  −0.079) and loses both GT files on eShopOnWeb T3. Also: ~33 MB first-use
  model download and a per-pack stderr warning for installs without the
  `[semantic]` extra make it a poor default for offline users. The ranker
  constructor default is reverted to `False`, matching the CLI
  (`--with-semantic`) and `Orchestrator.build_pack` defaults that never
  changed. Deviation from roadmap spec is deliberate and evidence-based.
- **C3 ABS_FLOOR 0.45 → 0.40 — KEEP (neutral post-hygiene).** Already shipped
  in 14d6462 with structural gate tests. Ablating back to 0.45 changes nothing
  on the 12 tasks (post-hygiene confidences sit clear of the 0.40–0.45 band),
  and the original motivation (recovering borderline items cut by the plateau
  rule) is still sound. Reverting would only churn pinned tests.

## Method notes

- First semantic run was invalid: torch wheels (Intel mac caps torch at 2.2.2)
  compiled against NumPy 1.x crashed under the project's NumPy 2.4.4, so
  "semantic" silently equaled lexical. Re-run with `numpy<2` +
  `transformers<4.50` pinned; confidences then visibly shifted, confirming the
  boost applied.
- Pack L2 cache was busted between A/B configs by touching
  `.context-router/context-router.db` (repo_id derives from DB mtime).
- The roadmap C2 gate test (`benchmark --fixtures benchmark/tuning`) was not
  added: no `benchmark/tuning` fixture set exists, and the holdout set is
  reserved for v4.5 Task 9.
