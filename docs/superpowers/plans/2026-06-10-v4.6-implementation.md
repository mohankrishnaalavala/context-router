### T2 — A1+A2+A3: edge dedup, symbol qualification, count consistency

**Owns:** `packages/storage-sqlite/` (migration + `repositories.py`),
`packages/graph-index/` (`writer.py`, scanner/analyzer symbol identity),
index summary reporting, their tests. TDD: failing test first per sub-item.

1. **A1 dedup:** migration adds `UNIQUE(repo, from_symbol_id, to_symbol_id,
   edge_type)` (rebuild `edges`, collapse existing dupes keeping
   `weight = SUM(weight)` or occurrence count); `EdgeRepository.add_bulk`
   (`repositories.py:927`) pre-aggregates duplicates in the batch into
   weight, then `INSERT OR IGNORE` + `ON CONFLICT` weight update for the
   re-index path. Confirm degree/community ranking reads weight.
2. **A2 qualification:** edge resolver (`writer.py:107–267`) and symbol rows
   gain scope-qualified identity (parent symbol chain, e.g.
   `module.test_foo.Model`); keep short display name for retrieval (FTS and
   name lookup must still match "Model"). Bump cache/schema version so stale
   `pack_cache` is discarded with a named WARN, not served.
3. **A3 count:** the `index` summary's edge count must be the post-dedup
   stored count (`SELECT count(*)`), identical on immediate re-run; per-file
   incremental updates keep reported == stored.

DoD ids: `v4.6-edge-dedup`, `v4.6-symbol-qualification`,
`v4.6-edge-count-consistency`. Negative cases there are mandatory tests.
